# Crop Doctor AI 🌱

**AI-powered crop disease detection and farmer advisory.**

Crop Doctor AI is an offline-first application under development to help farmers identify crop diseases from leaf images and access crop health guidance.

## 🌾 Supported Crops

* Tomato
* Potato
* Apple
* Corn

## ✨ Planned Features

* Crop disease detection from leaf images
* Farmer-friendly disease guidance
* English, Hindi, and Gujarati language support
* Offline access for areas with limited internet connectivity

## 🛠️ Technology Stack

* **Frontend:** React, Vite, TypeScript
* **Backend:** Python, FastAPI
* **AI model:** PyTorch, MobileNetV3
* **Browser inference:** ONNX Runtime Web
* **Database:** SQLite

## 🚧 Development Status

This project is under development. The current demo uses mock predictions; the real AI model has not yet been trained and validated. Offline AI inference is planned.

## 📂 Project Structure

* `frontend/` — Web application
* `backend/` — API server
* `ai/` — AI development
* `scripts/` — Dataset and training utilities
* `docs/` — Project documentation
* `tests/` — Testing
